# ROADMAP

- [x] Generate an OTF/TTF font from monogram letter SVGs (in-memory map, ZIP, or files on disk)
- [ ] Support `<g>`/`transform` and non-`<path>` shapes (`<circle>`, `<rect>`, etc.) when reading monogram SVGs
- [ ] Optional raster (PNG/JPG) input via auto-vectorization, for monogram sets that aren't already vector art
- [ ] WOFF2 output, for smaller web-font payloads in `maker-toolkit` / `maker-template-pro`
- [ ] CLI for generating a font from the command line without writing code
